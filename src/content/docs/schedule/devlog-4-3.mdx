### DevLog 4-3 

#### Create a database-driven application using Node/Express/MongoDB 


Use Node.js and MongoDB Atlas to create the back end for Big Feelings. Then publish your full-stack application on Vercel. Follow Modules 10.3 in Critical Web Design and [Module 10.4 on the CWD Wiki](https://criticalwebdesign.github.io/wiki/chapter-10/10-4-big-feelings/) to complete your DevLog. <DevLogInstructions filename="devlog-4-3.mdx" />

1. Fork the [criticalwebdesign/big-feelings-starter](https://github.com/criticalwebdesign/big-feelings-starter) and update it per Module 10.3. 
1. Modify the project structure, install dependencies, and run the project.
1. Create a MongoDB Database (CWD 10.4)
1. Create an `.ENV` file, add your connection credentials, and test your database connection (CWD 10.4)
1. Add routes to get data from MongoDB (CWD 10.4)
1. Allow Visitors to Submit Feelings (CWD 10.4) 
1. Add an environment variable and deploy your project on Vercel. (CWD 10.4) 
1. Read 📚 [ICE Is Going on a Surveillance Shopping Spree](https://www.eff.org/deeplinks/2026/01/ice-going-surveillance-shopping-spree), EFF 2026. Post a reading response in your DevLog per information in the [Assignments](./#assignments). ✏️
